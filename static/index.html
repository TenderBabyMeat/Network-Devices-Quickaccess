PuTTY buttons on this PC

Browsers can't start programs by themselves, so each Linux PC where you want the PuTTY buttons needs a small link handler, installed once. Web SSH needs nothing.

  1. Download the PuTTY link handler for Linux
  2. Extract it and run the installer (no sudo needed): 
    tar xzf netdevices-putty-linux.tar.gz
netdevices-putty/install.sh
  3. The first time you click PuTTY, the browser asks which app to use: pick PuTTY link handler (NetDevices), not plain “PuTTY”, and tick “Always”.

PuTTY opens but doesn't load the session? Run ~/.local/share/netdevices/putty-handler.sh --watch, then click a PuTTY button.
